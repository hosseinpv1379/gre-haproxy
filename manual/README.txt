# راهنمای دستورات دستی VortexL2
# این پوشه شامل دستورات لینوکس مستقیم برای انجام تمام کارهای VortexL2 بدون استفاده از اسکریپت است

## فهرست فایل‌ها:

1. **01-naghdiat-va-module-ha.txt**
   - نصب پیش‌نیازها و ماژول‌های کرنل L2TP
   - لود کردن ماژول‌ها و تنظیم لود خودکار در بوت

2. **02-sakht-tunnel-l2tp.txt**
   - ساخت تونل L2TPv3 برای سمت IRAN
   - دستورات کامل از ساخت تونل تا اختصاص IP

3. **03-sakht-tunnel-kharej.txt**
   - ساخت تونل L2TPv3 برای سمت KHAREJ
   - مقادیر شناسه‌ها با IRAN جابجا شده

4. **04-hazf-tunnel.txt**
   - حذف تونل و سشن L2TP
   - ترتیب صحیح حذف (ابتدا سشن، سپس تونل)

5. **05-port-forwarding-haproxy.txt**
   - تنظیم Port Forwarding با HAProxy
   - ایجاد فایل تنظیمات و راه‌اندازی HAProxy

6. **06-barrasi-vaziat-tunnel.txt**
   - بررسی وضعیت تونل‌ها و اتصالات
   - دستورات عیب‌یابی و مانیتورینگ

7. **07-firewall-l2tp.txt**
   - تنظیم فایروال برای پروتکل L2TP
   - استفاده از iptables یا nftables

8. **08-systemd-service-tunnel.txt**
   - ایجاد سرویس systemd برای راه‌اندازی خودکار تونل
   - راه‌اندازی تونل در بوت

9. **09-systemd-service-haproxy.txt**
   - تنظیم سرویس systemd برای HAProxy
   - مدیریت سرویس HAProxy

10. **10-tunnel-haye-chandgane.txt**
    - ساخت چندین تونل همزمان
    - مدیریت تونل‌های متعدد با شناسه‌های مختلف

11. **11-troubleshooting.txt**
    - عیب‌یابی مشکلات رایج
    - حل مشکلات معمول در تونل‌ها و Port Forwarding

12. **12-pak-kardan-va-hazf.txt**
    - پاک‌سازی کامل تنظیمات
    - حذف تمام تونل‌ها، سرویس‌ها و فایل‌های پیکربندی

## نحوه استفاده:

1. ابتدا فایل 01 را اجرا کنید تا پیش‌نیازها نصب شوند
2. برای ساخت تونل، فایل 02 (IRAN) یا 03 (KHAREJ) را استفاده کنید
3. برای Port Forwarding، فایل 05 را استفاده کنید
4. برای عیب‌یابی، فایل 11 را بررسی کنید

## نکات مهم:

- تمام دستورات باید با دسترسی root (sudo) اجرا شوند
- مقادیر IP و شناسه‌ها را با مقادیر واقعی خود جایگزین کنید
- قبل از حذف تونل، مطمئن شوید که سرویس‌های وابسته متوقف شده‌اند
- برای تونل‌های متعدد، از شناسه‌های منحصر به فرد استفاده کنید

## مثال سریع:

```bash
# نصب پیش‌نیازها
sudo bash -c "$(cat 01-naghdiat-va-module-ha.txt)"

# ساخت تونل IRAN (با جایگزینی مقادیر)
sudo bash -c "$(cat 02-sakht-tunnel-l2tp.txt)"

# بررسی وضعیت
sudo bash -c "$(cat 06-barrasi-vaziat-tunnel.txt)"
```

## توجه:

این دستورات به صورت مستقیم از خط فرمان لینوکس قابل اجرا هستند و نیازی به اسکریپت ندارند.
هر فایل شامل دستورات مرتبط با یک کار خاص است.
